  # Kestrel Filer

  [![Tests](https://github.com/kurokoji/kestrel/actions/workflows/tests.yml/badge.svg)](https://github.com/kurokoji/kestrel/actions/workflows/tests.yml)
</div>

Windows専用・超軽量なデュアルペインファイラー。C++23 + 素のWin32 API / Windows Common Controls のみで実装しており、Electron・Qt・wxWidgets・WinUI・WPF・MFC・.NET などのフレームワークは一切使用していません。

コンセプトは Windows 2000 / Classic UI、CDE/Motif、Midnight Commander のような、密度の高いクラシックなデスクトップアプリです。見た目だけでなく、実装自体も軽量であることを目指しています。

## 特徴

- **起動が速い・依存が少ない**: 単一exe、標準DLLのみ、静的CRTリンク
- **ツリー + 左右2ペイン構成**、ドラッグ可能なスプリッター（移動中は点線ガイドを表示し、マウスを離すとサイズを確定）
- ツリーは遅延読み込み（展開時にのみ子ノードを取得、バックグラウンドスレッドで非同期）
- ツリーの「PC」クリックでドライブ一覧（This PC相当、空き容量/合計容量も表示）を表示
- ツリーの「ゴミ箱」クリックで中身を一覧表示（シェルの名前空間経由で列挙、名前・種類・サイズ・更新日時を表示）。右クリックでWindows標準の項目（元に戻す・削除・プロパティ等）を表示、Deleteキーで完全削除、タブ列下の「ゴミ箱を空にする」ボタンで空に（いずれも確認はシェル自身が表示）。並べ替え・リネーム・切り取り/コピー/貼り付け・外部へのドラッグは対象外
- 列見出しクリックで並べ替え（並べ替え中の列見出しに ▲/▼ を表示）
- 種類列はエクスプローラーと同じ種類名（「テキスト ドキュメント」等、拡張子ごとにシェルから取得）
- 各ペインに**タブ**（独立した履歴・ソート状態、先頭にドライブレターを色分けバッジ表示、多数開くと複数行に折り返し、ドラッグで並び替え可能。フォルダーやツリーのノードを中クリックで新しいタブ（裏で開く）、タブを中クリックで閉じる。ファイルをタブへドロップするとそのタブのフォルダーへ、少し留まるとそのタブに切り替わる）
- **プレビュー**ペイン（画像はGDI+、動画はシェルのサムネイル、テキストは先頭数KB）
- 右クリックで**Windows標準のシェルコンテキストメニュー**を表示（ファイル一覧・ツリーとも。「名前の変更」「新しいタブで開く」も追加）。一覧の空白部分ではフォルダー自体のメニュー（新規作成・ターミナルで開く・プロパティ等）、Shiftを押しながらで拡張項目（PowerShellをここで開く等）も表示
- 一覧で文字を入力すると、その文字で始まる項目へジャンプ
- **ドラッグ&ドロップ**: ファイル一覧・ツリーのフォルダーから外部アプリ（Explorer・ブラウザ等）へのドラッグに加え、ファイル一覧・ツリーへのドロップにも対応。フォルダー行/ツリーのノードに重ねるとそのフォルダーへ、一覧の空白部分なら表示中のフォルダーへ。移動/コピーの判定（同じドライブなら移動、Shift/Ctrl/Alt修飾、右ドラッグのメニュー）や zip・exe へのドロップ、ゴミ箱へのドロップはエクスプローラーと同じ（シェル自身のドロップ処理に委譲）。ドラッグ中は一覧の上下端で自動スクロール、ツリーのノードに少し留まると展開
- **セッション永続化**（ウィンドウ位置・タブ・スプリッター位置・列幅・UIフォントを次回起動時に復元）
- **UIフォント変更**（ツール(T) > 設定(S) > フォント(F)、標準のフォント選択ダイアログ）
- **既定の並び順設定**（ツール(T) > 設定(S) > 並び順(既定)(O)、名前/種類/サイズ/更新日時 + 昇順/降順。新規タブに適用、開いているタブには影響しない）
- `ReadDirectoryChangesW` による**ディレクトリのライブ監視**（外部からの変更も自動反映）
- **アドレスバー**: パス補完（入力中に候補を表示）、`%USERPROFILE%` 等の環境変数、`..` や `sub` などの相対パス、`shell:Downloads` 等のシェルの場所に対応。ファイルのパスを入力するとそのファイルを開く
- **インクリメンタル検索**（現在のディレクトリ内、一致行をハイライト）
- ファイル操作（コピー/移動/削除/リネーム）は `IFileOperation` 経由でシェルに委譲（ごみ箱・進捗UI・競合解決はすべてOS標準）
- **元に戻す**（編集(E) > 元に戻す、Ctrl+Z、最大50件）: Kestrel 自身が行った名前の変更・新しいフォルダー・コピー・移動・ごみ箱への削除が対象。コピーと新しいフォルダーの取り消しはごみ箱へ移す。ドラッグ&ドロップや右クリックメニューのシェルのコマンドで行った操作は、結果をシェルから受け取れないため対象外
- **切り取り時のアイコン半透明表示**（標準エクスプローラー同様、貼り付け待ちのアイテムをアイコンだけ薄く表示）
- ディレクトリ列挙は `std::jthread` でバックグラウンド実行、UIスレッドをブロックしない
- **シングルペイン表示**の切り替え
- 状態バーの右端に、アクティブなペインのドライブの空き容量/合計容量を表示
- **隠しファイル**の表示/非表示の切り替え（表示(V) > 隠しファイル(H)、設定は次回起動時も維持。ツリーは常に非表示）

## ビルド

Visual Studio 2022以降（MSVCツールセット）と CMake が必要です。

```bat
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

`build.bat` に、VS開発者環境を読み込んでビルドする一連のコマンドをまとめてあります。

生成される `build\kestrel.exe` は単体で動作します。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Enter` | 開く（フォルダは移動、ファイルは関連付けで開く） |
| `Backspace` | 親ディレクトリへ |
| `Alt+←` / `Alt+→` / `Alt+↑` | 戻る / 進む / 上へ |
| `Tab` | 左右ペインの切り替え |
| `Ctrl+L` | アドレスバーへフォーカス |
| `Ctrl+T` / `Ctrl+W` | 新しいタブ / タブを閉じる |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 次のタブ / 前のタブ |
| `Ctrl+F` | 現在のディレクトリ内を検索 |
| `Ctrl+Shift+T` | ツリーへフォーカス |
| `Ctrl+U` | シングルペイン表示の切り替え |
| `Ctrl+H` | 隠しファイルの表示/非表示 |
| `F2` | 名前の変更（拡張子を除いた部分を選択） |
| `F3` / `F4` | 表示 / 編集 |
| `F5` / `F6` | 反対側のペインへコピー / 移動 |
| `F7` | 新しいフォルダー（作成後そのまま名前の変更） |
| `F8` / `Delete` | 削除（ごみ箱へ） |
| `Shift+Delete` | 完全に削除（確認あり） |
| `Ctrl+C` / `X` / `V` | コピー / 切り取り / 貼り付け |
| `Ctrl+A` | すべて選択 |
| `Ctrl+Z` | 元に戻す（Kestrel で行った名前の変更・新しいフォルダー・コピー・移動・ごみ箱への削除） |
| `Alt+Enter` | プロパティ（未選択時は表示中のフォルダー） |
| マウス戻る/進むボタン | 履歴を戻る / 進む |
| 中クリック（フォルダー/ツリー） | 新しいタブで開く |
| 中クリック（タブ） | タブを閉じる |

## 構成

```
src/
  App.*             起動・COM/GDI+初期化・メッセージループ
  MainWindow.*       メインウィンドウ、メニュー/ツールバー/レイアウト/コマンド処理
  TreePane.*         ディレクトリツリー（遅延読み込み）
  FilePane.*         ファイル一覧ペイン（タブ、検索、ソート、選択）
  PreviewPane.*      プレビュー領域
  DirectoryModel.*   バックグラウンドでのディレクトリ列挙
  DirectoryWatcher.* ReadDirectoryChangesW によるライブ監視
  FileOperations.*   IFileOperation / ShellExecuteEx ラッパー
  IconCache.*        シェルのシステムイメージリストのキャッシュ
  Session.*          セッションの保存・復元（%APPDATA%\Kestrel\session.ini）
  Dialogs.*          軽量な自前ダイアログ（リソース不使用）
```

過剰な抽象化（DI、Event Bus、Service Locatorなど）は避け、必要最小限のクラス構成にしています。
